# Fantastic Planet Type

손그림 레터링 스케치 7종을 아무 문구(영문·숫자·한글)에 적용하는 타이포그래피 실험.

- 직접 그린 글자(F a n t s i c P l e …)는 스케치를 다듬은 벡터 그대로 사용
- 없는 글자는 뼈대 + 스타일별 붓 규칙으로 생성, 한글 11,172자 조합
- SVG / PNG 저장, `?t=문구&s=07&mode=all` 로 공유

```
npm install
npm run dev      # http://localhost:5331
npm run deploy   # GitHub Pages
```

`polished/` 스케치 완성본 SVG · `tools/` 스케치 정리·글자 추출(Python)
